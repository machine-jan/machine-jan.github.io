Machine Jan / Regenwald

🌿 REGENWALD

Ein generatives Ökosystem in Sonic Pi. Viele autonome Klangschichten – Regen, Waldboden, Vögel, Insekten, Affen, Raubtiere – überlagern sich zu einem räumlichen Wald, der nie gleich klingt. Der Regenwald ist auch die Keimzelle der Waldschicht in HEAT!.

Versionen

  1. v21 – Tag und Nacht

    Cineastischer Gesamtmix mit Kompressor, Tiefpass und großem Hall. Alle 3 Minuten wechseln Tag und Nacht: tagsüber Singvögel, Revierrufe, hektische Kleinaffen und Brüllaffen, nachts Frösche, Großkatzen und ferne Raubtiere. Dazu vier Insektentypen und tiefe Waldenergie.

    Code
  2. v37 – Tiefenstaffelung

    Organisch lebendig, mit räumlicher Tiefe: Die Funktion forest_voice setzt jede Stimme fern, mittel oder nah – über Filter und Lautstärke. Mehrere sich überlappende Affen, zwei Vogelebenen, gelegentlich ein dominanter Ara, subtile Waldereignisse und sehr tiefe, ferne Glocken.

    Code

Ausprobieren

Sonic Pi installieren (kostenlos), Code öffnen, kopieren, in einen Buffer einfügen und auf Run drücken.
